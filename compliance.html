Operating

Compliance

Sinter assesses technical controls and produces evidence. It does not certify. That distinction is architectural, not a disclaimer, it determines what the subsystem is built to produce.

Sinter does
Assess

Check technical controls against code, config, and infrastructure. Generate evidence artifacts. Flag when a diff touches a controlled surface. Track drift between assessments.

Sinter does not
Certify

Issue an attestation or ATO. Substitute for a 3PAO, C3PAO, QSA, or lead auditor. Cover organisational controls. Determine whether you are in scope. Interpret ambiguous legal questions.

A control is never "met" on inference

Status is one of met (a check ran and passed), gap (a check ran and failed), needs-human-evidence, or not-assessable. Three of those are honest answers; guessing is not. A green dashboard that creates false confidence going into an audit is worse than no tool at all.

Assess once, map to many

SOC 2 CC6.1, ISO 27001 A.8.3, HIPAA section 164.312(a), and NIST 800-53 AC-2 are all access control. Nine independent checklists would triplicate the same work and drift apart within a release. Instead: one normalised control model, per-framework crosswalks, and a single technical check that emits evidence against every framework it satisfies. Adding a framework is a crosswalk entry, not a new checker.

/sinter:comply soc2 iso27001 --evidence

Control text is retrieved, never memorised

Control catalogues get revised. A stale crosswalk is confidently wrong, which is worse than absent. The framework files carry structure and engineering interpretation; current control text is retrieved at assessment time, and every report stamps the catalogue version it assessed against.

DORA means two different things

Here it is the EU Digital Operational Resilience Act. DORA metricsdeployment frequency, lead time for changes, change failure rate, time to restore: are unrelated and live in the observability and release skills. Both skill descriptions carry negative clauses so the trigger surfaces do not collide.
